# TRACE Theme Palette

TRACE uses the two supplied Realtime Colors palettes as product themes.

## Dark mode

- Text: `#caced3`
- Background: `#060709`
- Primary: `#28406d`
- Secondary: `#611a3d`
- Accent: `#5a271e`

## Bright mode

- Text: `#090c10`
- Background: `#f6f7f9`
- Primary: `#5e77a6`
- Secondary: `#cca3b7`
- Accent: `#be9189`

The selected theme is persisted in local storage under `trace_theme` and can be switched from the top navigation or authentication screen.

## Final visual QA

The final UI uses Manrope for product text and DM Serif Display for editorial display headings, with Space Mono for technical metadata. The supplied video assets are not hue-shifted or brightness-filtered in dark mode; only a transparency overlay is used to preserve text legibility. The Memory Lab comparison cards and page typography are scaled for normal 100% browser zoom.
